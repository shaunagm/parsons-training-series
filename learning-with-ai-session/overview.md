# Sharpen Your Tech Skills with AI — Class Overview

**Parsons Party · ~60 minutes · technical session**

**Session question:** *How do I use AI to learn more — not less?*

AI can flatten your skills — or sharpen them, if you’re deliberate. Today we practice using AI as a **tutor**, not a replacement for thinking: start small, ask questions, verify against the real world, capture what you understand, and keep humans in the loop.

## The learning loop

| Step | Who | What |
|------|-----|------|
| **Scope** | You + agent | Small learning project (~1 hour or less). Name **example A** (agent builds) and **example B** (you build next). |
| **See one** | You watch | Agent builds A. Summarize, walk line by line, ask questions, **verify** one claim against official docs. |
| **Do one** | You try | Build B with A as reference. Agent **nudges** — doesn’t replace your attempt. |
| **Teach one** | You → a person | Explain what you learned to a peer or mentor. Corrections welcome. |

**Revisit scope anytime.** If the agent dumps something too big to review, pause and say: *“This is too large. Let’s make the scope smaller. What are some smaller ideas?”*

---

## Habits that keep you learning

1. **Ask relentlessly** when something is fuzzy.
2. **Verify** at least one claim against real docs (or by running the code/query).
3. **Capture only what you truly understand** in `lessons.md`. If you’re not sure you understand, try explaining it in your own words, asking the agent to clarify, walking through an example, or finding a human to explain it to you.
4. **Bring humans in:**
   - Mentors (especially in your org) can help you choose *what* to learn next
   - Teach one — explain to a peer/mentor
   - Pair learn with a friend while you both use the agent
